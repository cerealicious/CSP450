STEP 1 Stage 2 Infrastructure & Networking Verification
1A. Client VM Verification (akarki5-Client)
1. Renew DHCP Lease:
sudo dhclient -r && sudo dhclient -v Expectation: Pulls dynamic IP in range 172.16.53.132 - 172.16.53.189 with gateway 172.16.53.129.
2. Internet Access by FQDN: Open Firefox browser and visit: https://www.youtube.com Expectation: Loads YouTube homepage directly (Proves DNS interception and NAT forwarding).
3. Traceroute to Local Router:
traceroute 192.168.3.90 Expectation: Hop 1 is VIP 172.16.53.129, Hop 2 is Router WAN address 192.168.3.90.
4. Traceroute to YouTube (Outbound Internet Path):
traceroute youtube.com Expectation: Hop 1 is VIP 172.16.53.129, Hop 2 is Router 192.168.3.90, then exits out SenecaNet.
1B. Server VM Verification (akarki5-Server @ 172.16.53.190)
1. Renew Lease & Static Reservation Check:
sudo dhclient -r && sudo dhclient -v Expectation: Core Switch DHCP static-bind locks Server IP exactly to 172.16.53.190 (MAC: 00:50:56:20:37:EB).
2. SSHtest Password Disabled Test:
From akarki5-Client VM, attempt SSH: ssh SSHtest@172.16.53.190 Expectation: Returns "Permission denied (publickey)" proving password authentication is strictly disabled in sshd_config.
3. Server Internet Ping Test:
ping -c 4 www.google.ca Expectation: 4 ICMP replies received with 0% packet loss.
1C. Router VM Verification (akarki5-Router @ WAN IP 192.168.3.90)
1. NFTables Firewall & NAT Ruleset:
sudo nft list ruleset | less Expectation: Prerouting preroutes UDP/TCP port 53 to DNS 10.101.100.21, and postrouting masquerades ens33.
2. OSPF Dynamic Routing Engine:
sudo vtysh show ip ospf show ip route Expectation: OSPF Process ID 214.1.1.2 active in Area 0; routing table lists routes marked with "O" code.
